Как создать Telegram-бота с AI за 200$

28 июля 2026 · 8 мин чтения

Telegram-бот с искусственным интеллектом — это не sci-fi. Это реальный инструмент, который стоит от 200$ и окупается за месяц. В этом руководстве я покажу, как создать бота, который отвечает на вопросы клиентов 24/7.

Зачем бизнесу AI-бот?

Обычный бот отвечает на 5-10 предустановленных вопросов. AI-бот понимает любой вопрос и отвечает осмысленно. Для бизнеса это значит:

  • 60% вопросов решаются без участия человека
  • 24/7 доступность — клиенты получают ответы ночью и в выходные
  • Экономия времени — менеджеры занимаются сложными задачами
  • Сбор лидов — бот автоматически собирает контакты

Выбор AI модели

Для Telegram-бота подходят три основных модели:

1. Cohere (c4ai-aya-expanse-32b)

  • Бесплатный тир: 100 запросов в минуту
  • Качество: хорошее для русского языка
  • Скорость: 2-3 секунды
  • Стоимость: $0 (бесплатно)

2. OpenAI (GPT-4o-mini)

  • Бесплатный тир: нет
  • Качество: отличное
  • Скорость: 1-2 секунды
  • Стоимость: $0.15 за 1M токенов

3. Google Gemini

  • Бесплатный тир: 60 запросов в минуту
  • Качество: хорошее
  • Скорость: 2-4 секунды
  • Стоимость: $0 (бесплатно)

Мой выбор: Cohere — бесплатно, работает с русским языком, достаточно быстрый.

Пошаговая инструкция

Шаг 1: Создаём бота в Telegram

  1. Откройте Telegram и найдите @BotFather
  2. Отправьте команду /newbot
  3. Введите имя бота (например, "WebStudio Bot")
  4. Введите username (например, "WebStudio_bot")
  5. Получите API токен

Шаг 2: Настраиваем сервер

Используем PythonAnywhere (бесплатный тир):

  1. Зарегистрируйтесь на pythonanywhere.com
  2. Создайте новый файл flask_app.py
  3. Вставьте код (см. ниже)
  4. Настройте webhook

Шаг 3: Код бота

Вот рабочий код Flask-бота с Cohere:

from flask import Flask, request, jsonify
import cohere
import requests

app = Flask(__name__)
co = cohere.Client('YOUR_API_KEY')
BOT_TOKEN = 'YOUR_BOT_TOKEN'

@app.route('/api/chat', methods=['POST'])
def chat():
    data = request.json
    user_message = data.get('message', '')

    prompt = """Ты — помощник веб-студии WebStudio.
    Отвечай о создании сайтов, Telegram-ботов и SEO.
    Будь полезным и конкретным."""

    try:
        response = co.generate(
            model='c4ai-aya-expanse-32b',
            prompt=f"{prompt}\n\nКлиент: {user_message}\nПомощник:",
            max_tokens=500,
            temperature=0.7
        )
        reply = response.generations[0].text.strip()
        return jsonify({'reply': reply})
    except Exception as e:
        return jsonify({'reply': 'Ошибка. Попробуйте позже.'}), 500

@app.route('/webhook', methods=['POST'])
def webhook():
    data = request.json
    message = data.get('message', {})
    chat_id = message.get('chat', {}).get('id')
    text = message.get('text', '')

    if text == '/start':
        reply = 'Привет! Я AI-помощник WebStudio. Задайте вопрос о сайтах и ботах.'

    requests.post(
        f'https://api.telegram.org/bot{BOT_TOKEN}/sendMessage',
        json={'chat_id': chat_id, 'text': reply}
    )
    return jsonify({'ok': True})

Шаг 4: Настраиваем webhook

Отправьте запрос для настройки webhook:

https://api.telegram.org/botYOUR_TOKEN/setWebhook?url=https://YOUR_DOMAIN/webhook

Шаг 5: Тестируем

  1. Найдите вашего бота в Telegram
  2. Отправьте /start
  3. Задайте вопрос
  4. Получите ответ от AI

Частые ошибки

  1. Плохой промпт — AI отвечает мусором. Пишите четкие инструкции.
  2. Нет ретрая — PythonAnywhere засыпает. Добавьте цикл с повторами.
  3. Нет логирования — не знаете, что спрашивают. Логируйте все диалоги.
  4. Нет ограничений — бот тратит весь бюджет. Ограничьте длину ответа.
