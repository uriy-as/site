# Мониторинг цен конкурентов

Парсер публичных прайсов веб-студий и Telegram-бот разработчиков: собирает цены,
сравнивает с предыдущим запуском, показывает изменения и отправляет алерт в Telegram.

## Что делает

1. Загружает список источников из `sources.json` (CSS-селекторы задаются на каждый сайт).
2. Проверяет `robots.txt` перед запросом, отправляет вежливый `User-Agent`, ставит паузу между запросами.
3. Ищет цены в валютах `₴ грн UAH`, `€ EUR`, `$ USD`, `₽ RUB` с учётом украинских/русских написаний.
4. Отбрасывает зачёркнутые («старая») цены, разбирает диапазоны, чистит подписи услуг.
5. Сравнивает с `state.json` и считает изменение в процентах.
6. Формирует HTML-отчёт и отправляет в Telegram всё, что изменилось выше порога.

## Запуск

```bash
pip install -r requirements.txt

python monitor.py                       # обычный запуск: обновить state, отчёт, алерты
python monitor.py --dry-run --no-alert  # проверить, не меняя state.json и не слать алерты
python monitor.py --only MaxWeb         # один источник
python monitor.py --threshold 10        # другой порог, %
python monitor.py --skip-local-only     # пропустить источники с "local_only": true
```

**Про `local_only`.** Некоторые сайты (например, за Cloudflare) отдают `403` на запросы с
серверов CI. Такие источники помечены `"local_only": true` — они собираются при запуске
с твоего компьютера (полная картина для отчёта), но пропускаются в автоматическом прогоне.

Переменные окружения для алертов (берутся по очереди): `TELEGRAM_TOKEN` / `TELEGRAM_BOT_TOKEN` / `TG_BOT_TOKEN`
и `ADMIN_CHAT_ID` / `TELEGRAM_CHAT_ID` / `CHAT_ID`. Без них скрипт не падает — печатает сообщение, которое было бы отправлено.

## Формат отчёта

`report.html` — таблица «источник / услуга / цена / Δ», старая цена зачёркнута,
изменения подсвечены (красный рост, зелёное снижение).

## Настройка источника

```json
{
  "name": "MaxWeb",
  "url": "https://maxweb.com.ua/price",
  "selector": ".pricing-grid .price-card",
  "max_items": 12
}
```

`label_selector` (необязательно) — элемент внутри карточки, из которого берётся название услуги.
`selector: null` — сканировать всю страницу (меньше точность, больше шума).

## Ограничения и этика

Только публичные страницы. Никакой авторизации, обхода защиты и персональных данных.
Пауза между запросами, `robots.txt`, один запрос на источник. Для регулярного сбора
конкурентов — согласовать с их `ToS`; инструмент рассчитан на разовый анализ и свои источники.
