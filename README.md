# uriy-as.site

Исходный код сайта **[uriy-as.org](https://uriy-as.org)** — веб-студия WebStudio.

Многостраничный сайт с i18n (RU/EN), встроенным AI-чатом, блогом и SEO-оптимизацией.

## Что внутри

- 70+ страниц: лендинги, блог (24 статьи), услуги, кейсы
- Блог на 24 статьи с перелинковкой 3-4 ссылки на каждую
- AI-чат (Flask + LLM) с резервной цепочкой моделей — работает 24/7
- Статистика посещений в реальном времени
- Schema.org JSON-LD: Article, FAQPage, BreadcrumbList, HowTo, LocalBusiness
- SEO: sitemap, robots.txt, hreflang (RU/EN), canonical, Core Web Vitals в зелёной зоне
- Защита: CSP, HSTS, X-Frame-Options, Permissions-Policy, Cloudflare

## Стек

HTML5, CSS3, JavaScript (vanilla), Python (Flask), GitHub Pages, Cloudflare
