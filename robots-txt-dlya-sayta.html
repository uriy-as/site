robots.txt для сайта: что это, пример и 7 ошибок 2026 года

Файл robots.txt из 15 строк управляет всей индексацией. Разбираем директивы Allow/Disallow, пример для сайта на 70 страниц и 7 ошибок, из-за которых сайт пропадает из Google.

Что такое robots.txt

Файл robots.txt — это текстовый файл в корне сайта, который подсказывает поисковикам, какие страницы можно сканировать, а какие закрыты. Он не влияет напрямую на позиции, но неправильный robots.txt может полностью исключить сайт из индекса. Google читает его при каждом обходе сайта, поэтому файл должен быть корректным.

Расположение: https://uriy-as.org/robots.txt. Пустые директивы Disallow игнорируются — закрывать страницы «на всякий случай» нельзя.

Пример базового robots.txt

Для корпоративного сайта из 70+ страниц достаточно 15–20 строк:

User-agent: * Allow: / # Служебные разделы Disallow: /parser/ Disallow: /stats.html Disallow: /gh-stats.html # AI-краулеры (трафик из AI-ответов) User-agent: GPTBot Allow: / Sitemap: https://uriy-as.org/sitemap.xml

7 ошибок в robots.txt

  • Disallow: / — закрывает весь сайт. Самая частая причина «пропал из Google».
  • Закрытие CSS/JS — поисковик не видит стили и ранжирует «слепую».
  • Disallow для служебных URL без нужды — /parser/, /api/, /stats — да; контент — нет.
  • Отсутствие Sitemap: — мелочь, но помогает индексации.
  • Дубли директив без User-agent — каждая группа правил начинается с User-agent.
  • Проверка по Google Search Console — раздел «Файл robots.txt» покажет ошибки.
  • Закрытие сайта на время разработки — не забыть открыть до релиза.

Как проверить файл

  • Откройте https://uriy-as.org/robots.txt в браузере — должен быть текст, а не 404.
  • GSC → Настройки → Файл robots.txt: должен отображаться без ошибок.
  • Робот: Googlebot и YandexBot получают 200 на всех страницах.
  • После правки — подождите 1–3 дня, Google перечитает файл.

Частые вопросы

Что такое robots.txt простыми словами?

Файл в корне сайта с правилами для поисковиков: что сканировать, а что нет. Ошибка в нём может полностью убрать сайт из выдачи.

Может ли robots.txt улучшить позиции в Google?

Напрямую — нет. Он только управляет сканированием. Но правильный robots.txt не мешает индексации и экономит краулинговый бюджет.

Что будет, если закрыть всё через Disallow: /?

Сайт полностью выпадет из индекса. Это самая частая причина жалоб «пропали из Google».

Нужно ли закрывать /parser/ и служебные страницы?

Да. Служебные разделы (/parser/, /stats, /api/) не нужны в выдаче и тратят краулинговый бюджет.
